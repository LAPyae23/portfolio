# Khin La Pyae Htun · Portfolio

Personal portfolio of a full-stack developer, built with Next.js, Tailwind CSS, and Framer Motion.

**Live site:** https://portfolio-seven-blue-87.vercel.app

## Featured project

**[FoodDash](https://github.com/LAPyae23/deli_app)** ([live demo](https://deli-app-eta.vercel.app)) is a food delivery platform for Yangon. It connects customers, restaurants, riders, and admins on one Next.js and MongoDB codebase, with live order tracking and analytics across 10,000+ orders.

## Other projects

- **[Invento](https://github.com/LAPyae23/stock)** ([live demo](https://invento-hazel.vercel.app)): bilingual warehouse inventory app with push-to-talk stock entry.
- **[Celestix Booking UI](https://github.com/LAPyae23/MovieticketEbookingsystem_frontend)** ([live demo](https://celestix-demo.vercel.app)): movie ticket booking frontend. The demo runs on sample data.
- **[UIT Intern Portal](https://github.com/LAPyae23/UIt-Intern_frontend)** ([live demo](https://uit-intern-demo.vercel.app)): internship platform for students, companies, and admins. The demo runs on sample data.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
